# Heglau — eine illustrierte Dorfreise

An illustrated portrait of Heglau, a Franconian village near Merkendorf. Explore the village's history, pottery, cabbage-growing traditions, and places to visit through a continuous camera journey controlled by scrolling.

**[Visit Heglau →](https://glaubi.net/heglau/)**

## The experience

- Five chapters connecting local history, crafts, regional traditions, and visitor information.
- A continuous video journey with responsive layouts and an illustrated fallback.
- Keyboard navigation and support for reduced motion, with an option to enable animation.
- Locally hosted media and fonts, without analytics or embedded third-party services.

## Run locally

Requires Node.js 20 or later. No package installation is needed.

```sh
npm run dev
```

Open [localhost:4173](http://localhost:4173).

For project structure, validation, media production, and deployment, see [AGENTS.md](AGENTS.md). The [Illustrated Scroll Site skill](skills/illustrated-scroll-site/SKILL.md) provides a reusable production workflow.
